# Knotty

- The interface and every text for the person are in Mexican Spanish; the code (names, files, logic and comments), the saved data, the prompts and the documentation are in English. The prompts ask the expert to write everything the person reads in Spanish (D33 in `docs/PROPUESTA.md`). `docs/PROPUESTA.md` and `docs/carpinteria/` are still in Spanish.
- Measures in millimetres. Hexagonal architecture: `src/architecture.test.ts` checks the boundaries between layers and between the groups of `src/domain/` (`materials`, `design`, `estimate`, `checks`, `editing`, `furniture`, `session`; no cycles).
- `docs/PROPUESTA.md` is the living document: decisions, invariants and open questions (the diary of each delivery goes in its PR). `CONTRIBUTING.md` says how to verify a change by what it touches (levels and table). `docs/workflows.md` says what to do and where each thing goes by what one wants to achieve (a request the chat understands alone, a new option or piece of furniture, a ficha with the expert).
- `docs/carpinteria/` is the domain reference (plywood, joints, finishes, measures, structure, glossary); if two documents disagree, `valores-de-referencia.md` wins. If asked «contesta como <experto>» or for a «mesa redonda», read `docs/carpinteria/expertos.md` and answer with that judgment and that voice.
- Before a PR: `npm run lint`, `npm run typecheck` and `npm test`. `npm run compare` and `npm run autonomy -- --ask` call real providers and cost tokens: by hand only.
- Debug tools («Entrañas de la madera» and the bench): the Konami code (↑↑↓↓←→←→BA), `Ctrl+Shift+D`, the switch in settings or `?debug` show a bar on the left of the whole app with one drawer per tool. «Exportar» in the log downloads a JSON with the commit, the expert (without keys), the design and every event. It always captures, even when hidden.
- Bench (a drawer of the bar): it runs the fixed cases of `src/application/bench/cases.ts` against the connected expert (it uses the person's key and costs tokens; each case opens in «Ver qué pasó»), and checks without the expert every variant of each module (one with findings is a Knotty bug). `npm run compare` uses the same cases and the same grading.
- Fichas (their own drawer): the reference furniture with its thumbnail, by room (the ones each ficha says in `rooms`; one can go in several) and with a search by code or name. The findings are the same ones `probe` keeps.
- Opening something from the bench or the fichas (a variant, a ficha or the design of a case) enters the sandbox: test designs in memory, the saved design is not touched and «Salir» brings it back. With the debug access the Studio adds the «Hallazgos» tab (what Knotty computes of the design, with the pieces by name and «Ver en el 3D»), the provider and model switch, and «Exportar ficha» (the candidate file for `probe`, only if the design is still its plan; also outside the sandbox, for a design the expert drew from photos).
