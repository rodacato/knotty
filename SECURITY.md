# Security

## Supported versions

Knotty is published from `main` to GitHub Pages; only that version gets fixes.

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/rodacato/knotty/security/advisories/new) (the repository's **Security** tab → **Report a vulnerability**). Please do not open a public issue or PR for it.

Say what is affected, how to reproduce it and what an attacker gains. The report stays private until a fix is published, and the advisory is published with it.
